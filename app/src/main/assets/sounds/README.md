# Bundled sounds

This folder ships with **placeholder** loops generated via ffmpeg
(`scripts/regen_placeholder_assets.sh`). They let the app run end-to-end
out of the box but are not licensed for distribution beyond development.

Replace each file with a licensed 60–120 s loopable MP3 at 192 kbps and
keep the filename:

* `rain.mp3`
* `fireplace.mp3`
* `ocean.mp3`
* `forest.mp3`
* `singing_bowls.mp3`
* `white_noise.mp3`

The IDs and titles for these files live in `PresetCatalog.kt`.
