# Bundled relaxation sounds

Place six royalty-free MP3 files here that match `PresetCatalog.builtIn`:

- `rain.mp3`
- `fireplace.mp3`
- `ocean.mp3`
- `forest.mp3`
- `singing_bowls.mp3`
- `white_noise.mp3`

Recommended:
- 192 kbps MP3, mono or stereo, 60–120 s loop with crossfade so it sounds
  continuous when `Player.REPEAT_MODE_ONE` is enabled.
- Total bundled size ≤ 25 MB to keep the APK small.

You can either source these from a royalty-free library (e.g. Pixabay,
Freesound CC0) or generate them through your AI Cloud Function and copy
the resulting MP3 files into this folder. See the `Generated audio prompts`
section of the project README.
